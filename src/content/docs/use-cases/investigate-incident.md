---
title: Investigate an incident
description: Collect evidence from connected systems and return a reviewable investigation record.
---

Use a Factory or automation to collect routine incident evidence while responders keep control of mitigation and production decisions.

## Gather context

An automation can read recent deploys, alerts, logs, issue history and repository changes from connected tools. It can summarize the evidence and attach notes or artifacts to the task.

## Set safe limits

Make investigation steps read-only unless a person explicitly approves a production action. Store credentials in SuperPlane secrets and limit each integration to the required access.

## Review the evidence

Treat agent conclusions as a starting point. Confirm timestamps, sources, affected systems and proposed causes before changing production.
