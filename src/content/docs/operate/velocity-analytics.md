Velocity connects completed Factory work with repository merge activity. Use it to understand delivery trends across a workspace and selected reporting period.

## Review the report

The report can show completed or merged work, success rate, cycle or execution time, intake sources and tracked model cost. Repository data must finish syncing before all comparisons are available.

## Compare useful groups

Review team, human-authored and Factory-authored delivery as context, not as a competition. Filter by repository and compare similar work over consistent time windows.

## Act on patterns

- Repeated failures can indicate weak intake criteria or missing checks.
- Long cycle time can indicate queued work, slow external services, or review delay.
- High unsuccessful cost can indicate repeated retries without a changed cause.
