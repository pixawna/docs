---
title: Workspace settings
description: Manage the identity, repositories, lines, automations and connections for a Factory.
---

Workspace settings define what the Factory can access and how its tasks move. Review the impact on active work before you change a repository, line, automation, or credential.

## Workspace identity

Use a name and description that identify the product area or team process. The user interface calls this resource a workspace; the API calls it a factory.

## Lines and automations

Edit a line to change its ordered stages, automation entry points, or concurrency. Create and test the required automations before you add them to production work.

## Connections

Keep source-control, agent, CI and tool connections current. Grant the smallest scope required and rotate credentials according to your organization policy.

## Before a change

Finish or pause affected work, record why the change is required and run one small task through the updated path before increasing volume.
