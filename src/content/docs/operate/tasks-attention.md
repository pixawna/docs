title: Tasks and Needs attention
description: Monitor active work, identify blocked tasks and decide the next safe action.
---

The task board shows where work sits in the Factory pipeline. Use **Needs attention** to find work that cannot continue without a person, missing access, or a clearer decision.

## Review active tasks

Open a task to inspect its description, current line position, automation executions, checks, pull requests, artifacts, comments and usage. Read the latest timeline event before you take action.

## Resolve attention items

1. Identify the step that stopped.
2. Read the error, check, or requested decision.
3. Provide the missing access or focused instruction.
4. Retry only when the cause has changed.
5. Stop or close work that is outside the approved scope.

## Protect the task record

Do not recreate a task to hide a failed attempt. Retries, comments, approvals and outcomes belong in the same chronological record.
