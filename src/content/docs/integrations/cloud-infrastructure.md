Cloud and infrastructure components let an automation inspect or change external systems. Use narrow credentials and approval gates for actions that affect production.

## Cloud providers

- [AWS](/components/aws)
- [Google Cloud](/components/googlecloud)
- [Microsoft Azure](/components/microsoftazure)
- [Oracle Cloud Infrastructure](/components/oraclecloudinfrastructure)
- [DigitalOcean](/components/digitalocean)
- [Hetzner Cloud](/components/hetznercloud)
- [Cloudflare](/components/cloudflare)

## Platforms and registries

Use [DockerHub](/components/dockerhub), [Coolify](/components/coolify), [Render](/components/render), [Cloudsmith](/components/cloudsmith), or [JFrog Artifactory](/components/jfrogartifactory) as part of build and delivery workflows.

Separate read access from change access where the provider supports it. Record approvals in the workflow before a destructive or production action.
